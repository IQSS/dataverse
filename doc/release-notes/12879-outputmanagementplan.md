# Add DataCite compatibility for resourceType OutputManagementPlan

Datasets with type `outputmanagementplan` now have the correct resourceType `OutputManagementPlan` in DataCite metadata format, as defined in the [schema](https://datacite-metadata-schema.readthedocs.io/en/4.5/appendices/appendix-1/resourceTypeGeneral/#).

For more information, see #12879 and #12880.
