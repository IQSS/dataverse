This release updates to the recommended Payara-7.2026.7 release and updates many of the third-party libraries Dataverse uses.

Upgrade instructions: 

~ Standard payara upgrade steps w.r.t. download, unzip, etc.

W.r.t. what has changed: 
domain.xml needs the following line added:
<jvm-options>--add-opens=java.base/java.lang.reflect=ALL-UNNAMED</jvm-options>

The file glassfish-acc.xml is replaced with the new payara-acc.xml

default-logging.properties has been updated. 

I'm not sure that either of these file changes are necessary, but I assume glassfish-acc.xml will stop being supported at some point, so I'd recommend adding a step to copy those files.
