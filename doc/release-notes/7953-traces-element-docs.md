### Documentation for User Traces by Element API

The "user traces" API has long allowed superusers to retrieve a single category ("element") of traces, such as `roleAssignments` or `guestbookEntries`, as CSV or JSON via `/api/users/$USERNAME/traces/$ELEMENT`. This endpoint is now documented in the API Guide. See [the guides](https://guides.dataverse.org/en/6.13/api/native-api.html#show-user-traces-element-api) and #7953.
