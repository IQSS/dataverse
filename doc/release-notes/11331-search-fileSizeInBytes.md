The User Guide has been updated to explain how to search for files above or below a certain size by entering a range query such as `fileSizeInBytes:[1048576 TO *]` in the search box. The Search API Guide now covers the same `fileSizeInBytes` field for use with the `fq` parameter. See [the guides](https://guides.dataverse.org/en/6.13/user/find-use-data.html#file-size-search) and #11331.
